# Участие в разработке FINYA HELPER

Спасибо за интерес к проекту.

## Перед изменениями

1. Создайте отдельную ветку от актуального `main`.
2. Не добавляйте реальные токены, `.env`, логи и runtime-файлы.
3. Сохраняйте совместимость с текущей архитектурой:
   `watchdog.py -> run_background.py -> bot.py`.

## Проверка кода

Перед отправкой изменений выполните:

```bash
pip install -r requirements.txt
python -m py_compile bot.py run_background.py watchdog.py
```


## Коммиты

Делайте небольшие и понятные коммиты. Сообщение коммита должно кратко описывать изменение.

Примеры:

```text
Fix Telegram reconnect handling
Improve watchdog recovery
Update GitVerse CI checks
```

## Запрос на слияние

В описании укажите:
- что изменено;
- зачем это нужно;
- как проверялось;
- есть ли изменения конфигурации или переменных окружения.

Изменения, содержащие секреты или ломающие запуск бота, не принимаются.
