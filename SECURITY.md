# Политика безопасности

## Поддерживаемая версия

Актуально поддерживается последняя версия ветки `main`.

| Версия | Поддержка |
| --- | --- |
| `main` | ✅ |
| Старые коммиты | ❌ |

## Как сообщить об уязвимости

Не публикуйте токены, содержимое `.env`, приватные логи и другие секреты в публичных задачах или комментариях.

Если проблема может раскрывать секреты или давать несанкционированный доступ, сообщите владельцу проекта приватно через Telegram: **@THKC_SQUAD_CREATOR**.

Для обычных ошибок без чувствительных данных можно создать задачу (Issue) на GitHub.

В сообщении укажите:
- краткое описание проблемы;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- версию/коммит;
- логи только после удаления токенов и персональных данных.

## Работа с секретами

Секреты хранятся только в GitHub Secrets (например, `TGCLOUD_TOKEN` для выката) или в настройках самого бота.
Коммитить реальные токены и другие секреты в репозиторий запрещено.
