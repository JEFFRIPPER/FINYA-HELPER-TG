# Финя · FINYA HELPER

Бот-помощник Сквада **T.N.K.C SQUAD** в Telegram: [@THKC_SQUAD](https://t.me/THKC_SQUAD).

С 8 октября 2026 Финя работает на [Telegram Serverless](https://core.telegram.org/bots/serverless):
код исполняет сам Telegram, база данных встроенная (SQLite), отдельный сервер не нужен.
Весь рабочий код лежит в [`serverless/`](serverless/), подробности по модулям в
[`serverless/README.md`](serverless/README.md).

## Что умеет

**Канал и личка**
- Главное меню из трёх кнопок: «Профиль Фини» (Mini App), «Сквад», «Ещё».
- Рассылка новых постов канала подписчикам и копирование постов в чаты Сквада (`/posts_on`).
- Автобан тех, кто сам вышел из канала, и чёрный список в админке.
- Админка владельца по разделам: рассылки, участники, товары SQUAD SHOP, сервис.

**XP, звания и клуб**
- XP за комментарии и реакции в обсуждениях, звания I–IX, «X · Основатель SQUAD» у владельца.
- Награда дня, квесты недели, ачивки, лавка за XP (рамки, цвет ника, титулы, темы графиков),
  опросы, рефералы, дни рождения, итоги недели.
- Баланс XP: перевод, казино и кости, фарм раз в час.

**Mini App «Профиль Фини»**
- Тёмный кроваво-красный стиль Сквада на Material 3: профиль, топ, клуб, ссылки и проекты Сквада.
- Панель владельца: участники, звания и XP, товары магазина, загрузка старой истории чата.

**Чат как у Ириса** (команды словами, полный список: «Финя, команды»)
- «Кто Я»: фото-график актива и профиль; «Моя Анкета» по всем чатам Сквада; «Чат Инфо».
- Стата за день, неделю, месяц и всё время, топы, ачивки чата.
- Репутация, отношения, браки (с датой начала), РП-команды, гражданство, должности Сквада.
- Ник, «о себе», награды со степенями 1–8, напоминания, «Финя, кто/инфа/выбери».
- Капча и антифлуд. Модерация выключена по умолчанию.
- Ответы Фини в группах с кнопкой «✖️ Закрыть», сами удаляются через сутки.
- Премиум-эмодзи в ответах и новости об обновлениях в топике CHANGELOG после каждого выката.

## Структура

```
serverless/
  tgcloud/
    handlers/      входящие апдейты Telegram
    endpoints/     API для Mini App (/api/profile, /api/club, /api/ranks, /api/shop, /api/history)
    lib/           логика: bot.js (меню и маршрутизация), chat.js (команды в чате), xp.js, club.js…
    schema.js      таблицы базы
  webapp/          Mini App: HTML, CSS, JS без сборки
  test/            тесты на node:test с локальной заменой sdk
  tools/           вспомогательные скрипты (картинки, карточки для сторис)
  tgcloud.json     настройки приложения Telegram Serverless
```

## Разработка

Нужен Node.js 22 или новее.

```bash
cd serverless
npm install
npm test
```

Тесты запускают модули бота с `test/shim/` вместо платформенного `sdk` (SQLite в памяти), реальный Telegram не нужен.

Правила для изменений:
- Каждый выкат добавляет запись наверх `CHANGES` в `serverless/tgcloud/lib/changelog.js`: из неё Финя пишет новость в чат.
- Новые данные хранятся в новых таблицах в `schema.js`. Существующие таблицы не меняются, чтобы миграция оставалась безопасной.
- После правки `webapp/app.js` или `style.css` нужно поднять `?v=` в `webapp/index.html`: Telegram кэширует Mini App.

## Выкат

GitHub → Actions → **Deploy to Telegram Serverless** → Run workflow:
- в поле подтверждения ввести `ПЕРЕЕЗД`;
- `drop_deprecated` оставить `false`.

Нужен секрет репозитория `TGCLOUD_TOKEN`. Workflow делает `tgcloud push` и `tgcloud migrate --safe`.
Если шаг «Deploy modules» упал с первого раза, достаточно перезапустить run.
