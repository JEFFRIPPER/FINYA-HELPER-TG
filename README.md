# FINYA HELPER

Telegram-бот с бесплатной схемой самовосстановления.

## Активность, XP и звания (2.4)

В главном меню появились **«Мой ранг»** и **«Топ участников»**. Профиль показывает
звание, общий XP, XP за текущую неделю и день, а также остаток до повышения.
Команды: `/rank`, `/top`, `/top week`. Недельный рейтинг начинается в понедельник
в 00:00 по Москве; общий XP и звание при этом не сбрасываются.

Начисления относятся к обсуждениям постов **@THKC_SQUAD**, а не к любым сообщениям
беседы. Комментарий должен принадлежать ветке автоматически пересланного поста
этого канала (учитываются и вложенные ответы).

- Комментарий: **+5 XP**, минимум пять букв/цифр, не чаще одного начисления в 60 секунд.
- Личная реакция на пост или комментарий в обсуждениях: **+1 XP**, один раз на
  сообщение, максимум 20 начислений в сутки.
- Общий лимит: **100 XP в сутки**, календарь по Москве.
- Повтор доставки события, смена эмодзи и снятие с повторной установкой не дают
  дополнительных баллов. Снятие реакции не уменьшает уже заработанный XP.
- Реакции на собственные комментарии, пересланные комментарии, команды, стикеры,
  сообщения от ботов и от имени канала не начисляют XP. Правка комментария не
  считается новым действием.
- Обычные реакции на пост в самом канале анонимны для бота, поэтому личный XP
  за них начислить нельзя. Анонимные участники не получают XP.

| XP от | Звание |
| ---: | --- |
| 0 | I · Искра |
| 100 | II · Звено |
| 300 | III · Клинок |
| 500 | IV · Страж Круга |
| 1000 | V · Вестник Свободы |

**X · Основатель SQUAD** закреплён за владельцем по Telegram ID. Остальные звания
выдаются автоматически и не дают права администратора. При повышении Финя
уведомляет участника в личке, если он уже обращался к боту.

### Подключение обсуждений

1. Добавьте Финю **администратором группы обсуждений** канала.
2. По умолчанию группа определяется автоматически из связи с каналом.
3. Проверка от владельца: **`/admin` → «Активность / XP»**.
4. При необходимости отправьте **`/xpchat` от аккаунта владельца в группе**.
   Для возврата к автоматическому определению используйте `/xpchat auto`.
   Можно также задать `XP_DISCUSSION_CHAT_ID` на сервере; эта переменная имеет
   приоритет над настройкой через команду.

Накопленный ранее актив не восстанавливается. Реакции учитываются для постов
и комментариев, ветку которых бот уже увидел после подключения. Комментарий
под старым постом можно учитывать, если входящее сообщение содержит ссылку
на автоматически пересланный корень обсуждения.

Баллы, профили, привязки веток и журнал защиты от повторов хранятся в **`xp.sqlite3`**
рядом с `state.json` в `FINYA_STATE_DIR` / Railway Volume / `runtime`.
На Railway подключите постоянный **Volume**, иначе при новом развёртывании
контейнера локальные данные потеряются. Для переноса базы остановите процесс
бота, затем копируйте закрытый `xp.sqlite3`; не копируйте только основной файл
работающей SQLite-базы с активным WAL.

## Рекомендуемый запуск

Запускай не `bot.py`, а:

```bash
python watchdog.py
```

Цепочка защиты:

`watchdog.py -> run_background.py -> bot.py`

- `bot.py` пишет heartbeat каждые 30 секунд.
- `watchdog.py` проверяет heartbeat раз в 15 секунд.
- Если heartbeat старше 120 секунд или процесс умер — launcher перезапускается.
- `run_background.py` перезапускает бота после исключений с backoff 3–60 секунд.
- Логи ротируются в `logs/bot.log` и `logs/error.log`.

## Windows: автозапуск бесплатно

1. Открой **Планировщик заданий**.
2. Создай задачу `FINYA HELPER`.
3. Триггер: **При входе в систему** или **При запуске компьютера**.
4. Действие: запуск программы `pythonw.exe`.
5. Аргументы: полный путь к `watchdog.py`.
6. В поле «Рабочая папка» укажи папку проекта.
7. Включи «Перезапустить при сбое» и запуск независимо от входа пользователя, если доступно.

Для проверки можно сначала запустить обычным `python watchdog.py`.

## Linux: systemd

Создай `/etc/systemd/system/finya-helper.service`:

```ini
[Unit]
Description=FINYA HELPER Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/path/to/FINYA-HELPER
ExecStart=/usr/bin/python3 /path/to/FINYA-HELPER/watchdog.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now finya-helper
```

Проверка:

```bash
systemctl status finya-helper
```

## Настройка токена Telegram

Токен нельзя записывать в исходный код или отправлять в Git. Перед запуском задай его одним из способов:

```bash
export TELEGRAM_BOT_TOKEN="токен_из_BotFather"
python watchdog.py
```

Или скопируй `.env.example` в локальный `.env` и замени значение-заглушку. Настоящий `.env` уже исключён через `.gitignore`.

## Авторассылка T.N.K.C SQUAD

Управление подпиской находится внутри раздела **«Статус»**. Пользователь может включить или выключить личные уведомления без отдельной кнопки в главном меню.

Когда в публичном канале **@THKC_SQUAD** выходит новый пост, бот автоматически копирует его всем подписчикам и добавляет кнопку **«Открыть пост в канале»**.

Для работы авторассылки бот должен получать публикации канала. В админ-панели FINYA HELPER есть переключатель **«Авто ТГК: ВКЛ/ВЫКЛ»**.

Дополнительно:
- повторный `/start` показывает короткое приветствие;
- управление подпиской перенесено в **«Статус»**, без отдельной кнопки в главном меню;
- в **«Новости»** автоматически показывается закреплённый пост канала;
- подписчик может запросить последний сохранённый пост;
- админ-статистика показывает новых, активных, неактивных и недоступных пользователей.

## Автоматический ЧС при выходе из канала

Финя блокирует обычного подписчика, который сам выходит из **@THKC_SQUAD**.
Бан бессрочный: вернуться в канал по ссылке нельзя, пока администратор не снимет
ограничение в Telegram. События удаления администратором, баны, выходы ботов и
изменения статуса администраторов не запускают эту функцию.

Настройка:

1. Назначьте Финю администратором канала с правом **блокировать участников**.
2. В `.env` при необходимости задайте `BLACKLIST_CHANNEL_ID`. По умолчанию
   используется проверенный ID канала @THKC_SQUAD: `-1001192817776`.
3. Обновите файлы проекта, включая `channel_blacklist.py`, и перезапустите бота.
   Для одного токена должна работать только одна копия polling-бота.
4. Откройте **`/admin` → «Чёрный список»** в личном чате с Финей.

Список доступен только владельцу с Telegram ID `7221285861`. В нём видны имя,
username (если есть), ID, дата выхода по Москве и результат бана. По пять записей
на странице, новые сверху. Кнопка **«Обновить»** обновляет список и проверяет права
бота в канале. ЧС относится к каналу; подписка на личную рассылку бота его не меняет.

Записи хранятся в `runtime/state.json` вместе с остальным состоянием. Этот файл
нужно сохранять при обновлении и переносе. Запись появляется до запроса бана;
при ошибке она не помечается успешной. Незавершённые запросы повторяются после
перезапуска и восстановления связи/прав. Перед повтором проверяется текущая роль:
администраторы и владелец не блокируются.

Функция обрабатывает полученные события выхода, в том числе для подписчиков,
которые никогда не писали боту. Историю выходов до подключения она не восстанавливает:
Telegram хранит необработанные обновления не дольше 24 часов.
Список показывает баны, выполненные этой функцией, а не весь исторический ЧС Telegram.

На Railway подключите постоянный **Volume** к сервису (например, `/data`): бот
автоматически использует `RAILWAY_VOLUME_MOUNT_PATH` для `state.json`. Либо задайте
`FINYA_STATE_DIR` с путём к постоянному диску. Без диска история в контейнере
потеряется при следующем развёртывании, хотя сами баны останутся в Telegram.
Если в контейнере уже есть `runtime/state.json`, сохраните его и перенесите в корень
Volume до первого запуска с диском, чтобы сохранить пользователей и настройки.

Проверка без реальных блокировок:

```bash
python -m unittest discover -s tests -v
python -m py_compile bot.py channel_blacklist.py run_background.py watchdog.py
```
