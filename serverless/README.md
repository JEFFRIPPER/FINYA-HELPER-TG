# FINYA HELPER на Telegram Serverless

Порт бота 2.6.2 с Python и Railway на [Telegram Serverless](https://core.telegram.org/bots/serverless).
Код запускается у Telegram, база — встроенная SQLite, сервер не нужен.

## Что где

| Было (Python) | Стало (`tgcloud/`) |
|---|---|
| `bot_core.py`, `bot.py` | `lib/bot.js` (маршрутизация, меню, команды), `lib/admin.js`, `lib/ui.js` |
| `activity_xp.py` | `lib/xp.js` |
| `admin_ranks.py` | `lib/rank_admin.js` |
| `channel_relay.py` | `lib/relay.js` |
| `channel_blacklist.py` | `lib/blacklist.js` |
| `state.json`, `xp.sqlite3` | таблицы в `schema.js` |
| `context.user_data` | таблица `sessions` |
| фоновые циклы asyncio | `pump()` в `lib/bot.js` + таблица `jobs` |
| `logs/*.log` | таблица `error_log`, кнопка «Логи» в админке |
| `watchdog.py`, heartbeat, «Перезапуск» | не нужны |

## Отличия от Python-версии

- **Фоновой работы нет.** Повторы постов в чаты, повторы автобана и хвосты рассылок
  выполняются при входящих апдейтах (не чаще раза в 30 секунд). В тихие часы
  досылка ждёт первого сообщения или нажатия. Рассылка владельца и рассылка поста
  подписчикам идут порциями; если порция не уложилась, владелец получает кнопку
  «Продолжить рассылку».
- **Статус** показывает хостинг и версию вместо аптайма, heartbeat и имени сервера.
- **Логи** — последние ошибки из базы.
- `XP_DISCUSSION_CHAT_ID`, `SQUAD_CHANNEL_ID`, `BLACKLIST_CHANNEL_ID` больше не переменные
  окружения (их на платформе нет), а константы в `lib/config.js`; группу XP по-прежнему
  можно привязать командой `/xpchat`.
- Картинка стартового экрана встроена в `lib/photo_data.js` (на платформе нет файловой системы).
  После первой отправки бот запоминает её `file_id`. Пересобрать: `python tools/embed_photo.py`.

## Mini App «Профиль Фини»

- `webapp/` — сам Mini App: обычные HTML, CSS и JS без сборки. Всегда тёмный, кроваво-красный
  со свечением (как у SQUAD VPN); формы, шрифтовая шкала и анимации из Material 3: ripple,
  fade through между вкладками, вход карточек с задержкой, индикаторы загрузки и прогресса.
  Цвета — токены в начале `style.css`. Иконки — Material Symbols и значки брендов Simple Icons,
  встроены в `app.js`.
- Сверху баннер Сквада (`webapp/img/`: логотип и обложка, сжатые в JPEG), ведёт в канал.
  Вкладка «Сквад»: объявление владельца (кнопка «Новость» в админке), быстрые кнопки,
  магазин Сквада и ссылки из меню «Сквад» (`SQUAD_LINKS` в `lib/config.js`, общие с клавиатурой бота)
  и проекты на GitHub (`PROJECTS` в `app.js`). Нажатые карточки подсвечивают рамку.
- Заголовки (баннер, новое звание, пасхалка) набраны кистевым Rubik Marker Hatch из `webapp/fonts/` (OFL, латиница и кириллица); остальной текст Roboto.
- Каждая вкладка нижней панели это отдельный экран: смена через fade through, прыжок наверх происходит, пока старый экран невидим. Карточка профиля только на «Активности».
- Погоны званий — `webapp/img/ranks/<I…X>.webp` (вырезаны из артов владельца). Карточки для
  сторис — `webapp/img/story/<звание>.jpg`, пересобрать: `node tools/story_cards.mjs <playwright> [chromium] [шрифты]`.
- В профиле: огонёк серии дней с XP, соперник выше в топе, кнопка «В сторис» (`shareToStory`),
  праздничный экран при повышении (последнее увиденное звание хранится в `localStorage`).
  Пять быстрых тапов по логотипу — пасхалка. Пустые прошедшие дни на графике «треснуты».
- Вкладка «Панель» видна только владельцу: поиск участников, распределение по званиям,
  выдача звания и XP с подтверждением. `endpoints/ranks.js` → `lib/rank_app.js`; изменения
  идут через те же `xp.adjustXp` / `xp.setManualRank` и журнал `admin_changes`, что и в боте.
  Внизу «Панели» карточка «Товары SQUAD SHOP» (см. ниже).
  После правок поднять `?v=` в `index.html`. `tgcloud.json` → `"static"`
  говорит `push` выложить эту папку; адрес — `WEBAPP_URL` в `lib/config.js`.
- `endpoints/profile.js` → `POST /api/profile`: ранг, прогресс, место, XP за 7 дней, история,
  топ и данные вкладки «Сквад». Кто открыл приложение, платформа проверяет сама (`ctx.initData.user`). В топе
  только имена и XP, без ID и юзернеймов.
- `endpoints/club.js` → `POST /api/club` (`lib/club_app.js`, логика в `lib/club.js`): награда дня
  (цикл 7 дней), квесты недели, ачивки, лавка за XP (рамки, цвет ника, титулы; тратится баланс
  «XP минус покупки», звание не падает), опросы, день рождения, личная ссылка-приглашение в канал.
  Бонусный XP пишется в `events` с `chat_id = 0` и ключом награды в `message_id` (`xp.grant`), поэтому
  каждая награда даётся один раз и не съедает дневной лимит 100 XP за комментарии и реакции.
  Владельцу: опросы и переключатели «Итоги недели», «Приветствие», «Поздравления с ДР» в «Панели».
- Фоном из `pump()` (`club.tick`): итоги недели в канал по понедельникам с 12:00 МСК (топ-3 получают
  +50/+30/+20 XP) и поздравления с днём рождения в обсуждениях с 10:00 МСК, каждое не чаще раза
  за неделю/день. Приветствие новичков: сервисное сообщение о вступлении в группе обсуждений.
  Рефералы: `chat_member` в канале со ссылкой участника (`ref_links`); засчитываются только новые.
- Открывается кнопкой «Профиль» у поля ввода (ставится один раз из `pump()`), кнопкой
  «Профиль Фини» в главном меню и «Открыть профиль» под «Мой ранг». В группах Telegram
  не разрешает такие кнопки, поэтому там она ведёт в личку: `t.me/<бот>?start=profile`.
- Меню бота компактное. Главное меню: «Профиль Фини», «Сквад» и «Ещё» (новости, рассылка, фидбек,
  партнёры, ЛС владельца). «Сквад» содержит «Все ссылки Сквада» (Mini App, `?tab=squad`), «Магазин» и «Правила».
  В личке одно живое меню: команды пользователя и прошлое меню удаляются (`tidyPrivate`).
  Ответы на /rank и /top в группах и сами команды удаляются через 2 минуты (таблица `autodelete`, `pump()`).
  Админка по разделам: «Рассылки», «Участники», «Товары SQUAD SHOP», «Сервис», плюс «Панель в Mini App».
  Список команд «/» ставится из `pump()` (`setMyCommands`, `commands_version`).
- После правки `webapp/app.js` или `style.css` подними `?v=` в `index.html`: Telegram
  кэширует страницы Mini App.

## Финя в чате (команды словами, как у Ириса)

Работает в чатах Сквада: в обсуждениях канала и в чатах с `/posts_on`. Код: `lib/chat.js` (разбор
команд и кнопки), `lib/members.js` (участники и актив), `lib/social.js` (репутация, браки, РП),
`lib/moder.js` (модерация, антифлуд, капча). Все команды: «Финя, команды».

- Профиль как у Ириса: «кто я», «кто ты» или «профиль» ответом. В группе это фото-график сообщений
  по дням за год (`lib/chart.js`, PNG без сжатия через `lib/png.js`), под ним подпись: роль в чате
  (создатель или админ), брак, звание, XP и место, ачивки, репутация, первое появление, последний
  актив, актив за день, неделю, месяц и всё время, «о себе» и награды. Без права на фото или в личке
  профиль уходит текстом.
- «+описание текст» (до 300 символов и 5 строк), «-описание», «описание» (своё или ответом) — `lib/bio.js`.
- Награды: админы чата и владелец пишут «наградить текст» ответом, снимают «снять награду N».
  «Награды» ответом показывает список с номерами. В профиле видны последние 5.
- «Финя, топ» показывает топ по XP.
- «стата» («топ дня / недели / месяца», «актив») открывает одну панель актива.
  - Кнопки панели: День, Неделя, Месяц, Всё время (`stat:*`). Панель редактируется на месте.
  - В панели: участники и сколько из них писали, список до 20 человек по сообщениям, внизу всего сообщений за период.
  Список участников живой: имя обновляется с каждым сообщением, а вышедшие (`chat_member`,
  сервисные сообщения) пропадают из топов, пока не вернутся.
- «фарм»: случайно 1–100 XP, с шансом 10% 101–200, раз в час (`xp.farm`, kind `farm`).
  Не входит в дневной лимит и в топ недели.
- Репутация: «+» или «спасибо» ответом на сообщение, без лимита. Повтор того же обновления
  не считается (`rep_votes`).
- Браки: «брак» ответом, второй принимает кнопкой (час на ответ). Ещё «развод» (с подтверждением),
  «мой брак» и «браки». Пара и репутация видны в Mini App.
- РП: «обнять», «поцеловать», «ударить»… ответом или с @ником, текст после действия идёт
  комментарием. В группе сама команда удаляется, ответ Фини встаёт ответом на сообщение участника.
  Владелец добавляет свои: «+рп пощекотать = щекочет 🤭», удаляет «-рп пощекотать».
- Развлечения: «Финя, кто…», «Финя, инфа…», «Финя, выбери А или Б», «Финя, вопрос?».
- Модерация ответом (выключена по умолчанию, `chat_moderation`; владелец включает «Финя, модерация вкл»).
  Её могут админы чата с правом блокировки и владелец: «мут 30м», «размут»,
  «бан», «разбан», «кик», «варн» (3 варна дают мут на сутки), «снять варн», «варны».
  Как у Ириса, в первой строке только команда и срок (м, ч, д, неделя, мес, год; число без
  единицы означает минуты), а причина пишется со следующей строки. Поэтому «бан бы тебе за такое» не банит.
- Защита (переключатели в «Панели» Mini App или «антифлуд вкл/выкл», «капча вкл/выкл» от владельца):
  - антифлуд даёт мут на 10 минут за 8 сообщений за 10 секунд;
  - капча: новичок молчит до кнопки «Я не бот», приветствие приходит после неё,
    а через 5 минут без нажатия `pump()` выкидывает новичка;
  - кикает только тех, кто всё ещё в муте капчи: бан или «размут» от админа капча не трогает;
  - тот, кто был в муте и перезашёл, кнопку не получает, иначе она сняла бы мут.
  - пересланные пачкой сообщения и альбомы флудом не считаются.
- Ответы на справочные команды (профиль, топы, стата, фарм, «+») удаляются через 2 минуты, как /rank.
  Команды не дают XP за комментарий.

### Премиум-эмодзи в ответах

Владелец кидает Фине в личку премиум-эмодзи, по одному из каждого пака. Можно одним сообщением, но без текста. Финя:
- через `getCustomEmojiStickers` узнаёт паки;
- забирает их целиком через `getStickerSet`;
- для каждого обычного эмодзи запоминает премиум-версию в таблице `premium_emoji`.

Правила выбора: присланный эмодзи главнее паков, а среди паков побеждает тот, что пришёл раньше.

Где применяется: ответы в чате (`lib/chat.js`, `lib/moder.js`, приветствие) проходят через `emoji.withPremium`.
- В тексте эмодзи оборачиваются в `<tg-emoji>`. Ссылки (имена в упоминаниях) и `<code>` не трогаются.
- У кнопок эмодзи в начале подписи становится иконкой.
- Если Telegram откажет (например, у владельца кончился Premium), уйдёт обычный текст.

Команды в личке: «эмодзи» показывает, что стоит сейчас; «эмодзи сброс» возвращает обычные.

### Новости об обновлениях (топик CHANGELOG)

Новости лежат в `lib/changelog.js`, в массиве `CHANGES`, свежая запись сверху. Каждый выкат бота или Mini App добавляет запись с новым `id`.

После выката `pump()` (шаг `changelog.tick`) сам публикует запись в привязанный топик. Привязка как у постов ТГК: `/log_on` прямо в нужном топике. Финя запоминает чат и топик (`changelog_target`), пишет «новости будут приходить сюда» (сообщение удаляется через минуту) и сразу публикует ждущую новость. Если писать туда она не может, владелец получает в личку ответ Telegram, привязка не меняется. До первой привязки используются `CHANGELOG_CHAT_ID` и `CHANGELOG_THREAD_ID` (ссылка `t.me/c/2229986493/271940`).
- Одна запись публикуется один раз (`changelog_posted` меняется одним запросом).
- Если ничего ещё не публиковалось, уходит только самая свежая запись.
- Если публикация не удалась, отметка снимается. Владелец один раз получает сообщение в личку. Следующая попытка будет через 30 минут.

Команды владельца:
- `/log` показывает следующую новость и куда она уйдёт.
- `/log post` публикует её сразу, не дожидаясь паузы после ошибки. При ошибке Финя отвечает, что сказал Telegram.
- `/log_on` в топике привязывает его.

В группе `/log` и `/log_on` можно дать и анонимным админом, если это чат Сквада или чат с новостями. Финя удаляет команду.

## Товары SQUAD SHOP

`/admin` → «Товары SQUAD SHOP» (`lib/shop_admin.js`): список товаров сайта, добавление,
удаление, скрытие, золотой бейдж и правка фото, названия (или числа звёзд), описания,
метки, категории и цены. Категорию можно выбрать кнопкой из уже существующих. Магазин статический, его товары лежат в `shop.json` репозитория
`JEFFRIPPER/SQUAD-SHOP`. Каждое изменение Финя коммитит туда через GitHub API, фото
кладёт в `img/p-<id>-<rnd>.jpg`, а старое удаляет. GitHub Pages обновляет сайт примерно
за минуту. Нужен ключ GitHub с Contents: Read and write на SQUAD-SHOP: владелец шлёт
`/shopkey <ключ>` в личку, Финя проверяет право записи, удаляет сообщение и хранит ключ
в настройке `shop_gh_token`.

То же в Mini App: «Панель» → карточка «Товары SQUAD SHOP» (`endpoints/shop.js` →
`shopAdmin.appHandle`). Товар правится в одной форме, фото браузер ужимает до 800px JPEG
и шлёт в base64.

## Переезд

1. Влить ветку в `main`: Railway пересоберёт старого бота с командой `/export`.
2. Владелец пишет старому боту `/export` и получает `finya-export-….json`.
3. Остановить сервис на Railway (не удалять: это путь отката).
4. Задеплоить: GitHub → Actions → «Deploy to Telegram Serverless» → Run workflow, ввести `ПЕРЕЕЗД`
   (нужен секрет репозитория `TGCLOUD_TOKEN`). Вручную то же самое:
   `TGCLOUD_TOKEN=app…:… npx tgcloud push`, затем `npx tgcloud migrate --safe`.
   `push` сам переключает вебхук бота на платформу.
5. Переслать боту файл выгрузки из шага 2: он импортирует всё и пришлёт итог.
6. Проверить: `/start`, админка, «Мой ранг», пост в канале.

Переезд выполнен 2026-10-08. Сервис на Railway удалён по решению владельца, поэтому
отката туда нет; резервная копия данных — файл выгрузки из шага 2.
